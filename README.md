# Анаит

Персональный ИИ-собеседник с долговременной памятью и Таро как инструментом осмысления ситуации.

## Канонический репозиторий

Этот репозиторий является основным источником истины проекта «Гадалка / Анаит».

## Ядро продукта

Главная ценность — не само гадание, а ощущение глубоко понимающего собеседника.

Анаит должна:
- помнить важные факты о человеке и изменения во времени;
- понимать контекст, отношения, повторяющиеся темы и незакрытые истории;
- использовать только релевантную память, не перечитывая всю переписку;
- давать реальную пользу бесплатно, но оставлять естественную потребность в углублении;
- общаться максимально человечно, по-свойски и тепло, а в важных вопросах — серьёзно и точно;
- избегать шаблонной эзотерики, канцелярита и дешёвых универсальных формулировок.

Таро — инструмент интерпретации. Продукт — понимание ситуации.

## Базовая схема

Сообщение пользователя → психологический разбор → релевантная память → Таро/интерпретация → ответ Анаит → обновление памяти.

## Секреты

Никакие реальные токены, API-ключи и пароли не хранятся в Git.

Для локальной разработки используется файл `.env`, который игнорируется Git. Шаблон переменных находится в `.env.example`.

Первый обязательный секрет:

```
TELEGRAM_BOT_TOKEN=
```

На сервере/хостинге это значение должно задаваться через Secrets / Environment Variables.
