# Журнал изменений

Все существенные изменения проекта фиксируются здесь.

## 2026-10-02

### Добавлено
- Зафиксирован канонический репозиторий проекта.
- Описано ядро продукта Анаит.
- Зафиксированы принципы персональной памяти.
- Зафиксирована модель бесплатной и платной ценности.
- Зафиксированы правила стиля общения.
- Добавлен безопасный шаблон переменных окружения.
- Добавлен запрет на хранение токенов и API-ключей в Git.
- Добавлена карта ключевых решений.
- Принято решение запустить второй отдельный Telegram-бот как Lite MVP.
- Lite MVP отделён от тяжёлой анимации, озвучки и премиальной сценической подачи.
- Текущая визуально сложная версия сохранена как кандидат для дорогих продуктов.
- Зафиксирована стартовая продуктовая лестница: 1 карта → 3 карты → 5–7 карт.
- Для второго бота предусмотрен отдельный секрет `TELEGRAM_BOT_TOKEN_LITE`.
- Добавлен универсальный клиент API Master.
- От Vercel отказались.
- Telegram переведён на Long Polling без webhook.
- Добавлен постоянный Node.js-процесс с автоматическим восстановлением после сетевых ошибок.
- Добавлены Dockerfile и Docker Compose для независимого 24/7 запуска.
- Выполнена синтаксическая проверка Node.js-файлов: ошибок не найдено.
